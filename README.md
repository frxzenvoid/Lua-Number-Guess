# 🎮 Number Guess Game

A simple console-based number guessing game written in Lua.

## Features

- 🎲 Random number generation (1–100)
- 💡 Higher/Lower hints
- 📈 Attempt counter
- 🏆 Performance rating
- 🎉 Friendly console interface

## Requirements

- Lua 5.3 or later

## How to Run

```bash
lua main.lua
```
